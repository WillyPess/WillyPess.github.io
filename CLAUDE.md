# CLAUDE.md

Personal portfolio site for Willy Pessoa, served by GitHub Pages from `main`
(https://willypess.github.io). Plain HTML, CSS and JS: `index.html`, `pages/`,
`assets/css/style.css`, `assets/js/script.js`. No build step.

## How to make changes

1. **Plan first.** Before editing, tell me what you will change and wait for my "yes".
2. **Never push to `main`.** Work on a separate branch.
3. **Always open a pull request** after pushing. I review and merge it in the app.
4. In the PR, show what changed and how you checked it (a screenshot for visual changes).

## Site notes

- Keep animations subtle and keep respecting `prefers-reduced-motion`.
- Stay free to host: GitHub Pages only, no paid services. Only a custom domain may cost money.
