About me

I'm a QA Engineer with 6+ years of experience in FinTech and enterprise environments, holding ISTQB CTFL certification. My background spans manual and automated testing across web applications, APIs, and database layers — with a consistent focus on preventing defects early and releasing software that works.

I design and implement test strategies from scratch: writing test plans, defining acceptance criteria, building automated regression suites with Cypress and Selenium, and validating APIs with Postman. I use SQL extensively to verify data integrity and trace root causes at the database level.

I thrive in Agile environments where quality is a shared responsibility, not a final gate. My goal is to bring structured QA thinking to an Australian team — bridging FinTech-grade testing rigour with modern automation practices.

What I'm Doing

  • Test Strategy & Planning

    Designing end-to-end test plans, risk-based coverage matrices, and acceptance criteria aligned with business requirements — from sprint kick-off to release sign-off.

  • Test Automation (Cypress / Selenium)

    Building automated regression suites with Cypress and Selenium in CI/CD pipelines — reducing release cycle time while maintaining consistent coverage.

  • API & Integration Testing

    Validating REST APIs with Postman and automated scripts — verifying contracts, status codes, payloads, and edge cases across service integrations.

  • Database & SQL Testing

    Writing SQL queries to verify data integrity, validate business logic at the database layer, and trace root causes of defects in relational systems (MySQL, PostgreSQL, SQLite).

  • Bug Analysis & Reporting

    Documenting defects with clear reproduction steps, severity classification, and impact assessment — using JIRA and TestRail to keep dev and QA aligned.

  • Agile QA & CI/CD Integration

    Embedding quality into sprint workflows — participating in refinement, writing shift-left tests, and integrating automated suites into Jenkins/GitHub Actions pipelines.
